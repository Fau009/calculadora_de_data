# Calculadora de Data

Uma calculadora de datas **bem visual**: conte o tempo entre duas datas, descubra idades com fase da lua e signo, some ou subtraia períodos e brinque com o calendário — tudo no próprio navegador.

**Abrir:** https://fau009.github.io/calculadora_de_data/

## O que dá para fazer

| Aba | O que faz |
|---|---|
| **📅 Entre datas** | Dias, semanas, meses, horas, minutos e segundos entre duas datas, com blocos grandes, resumo em anos/meses/dias e contagem de dias úteis × fins de semana |
| **🎂 Idade** | Idade exata contando **ao vivo**, anel de progresso e contagem regressiva para o próximo aniversário, dia da semana do nascimento, **signo**, signo chinês, **fase da lua** da noite em que nasceu e marcos de dias de vida |
| **➕ Somar/Subtrair** | Joga dias, semanas, meses e anos para frente ou para trás a partir de uma data base |
| **🌙 Fase da lua** | Lua desenhada com a iluminação real, porcentagem e quando vêm a próxima lua nova e a próxima lua cheia |
| **✨ Curiosidades** | Dia da semana, dia do ano, fase da lua, signo e contagem para qualquer data |

## Detalhes técnicos

- Um único `index.html` com HTML, CSS e JS puros, sem dependências.
- Todos os cálculos acontecem no aparelho; nada é enviado para lugar nenhum.
- Os últimos valores, a aba e o tema ficam salvos no `localStorage`.
- Tema claro e escuro. Instalável como app (PWA). Publicado pelo GitHub Pages.
